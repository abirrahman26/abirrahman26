### 🚀 Selected Engineering Projects

- **[BPL DataVault](https://github.com/abirrahman26):** Production-grade database management system for the Bangladesh Premier League built with **Oracle APEX, SQL, and PL/SQL**. Normalized from 1NF to BCNF, featuring **51 interactive pages**, 34 operational reports, 13 aggregate analysis views, and role-based permissions.
- **[ByteTrip](https://github.com/abirrahman26):** Web-based inter-district travel optimizer in **Python & Flask**. Computes Pareto-optimal routes considering transit fare schedules and regional transport constraints instead of simple geometric coordinates.
- **[CineSphere](https://github.com/abirrahman26):** Desktop cinema ticketing and theatre administration suite engineered with **Java, JavaFX, and MySQL**, with visual seating matrix allocation and transactional audit logging.
- **[Personal Portfolio & Blog Platform](https://github.com/abirrahman26/abirrahman):** Fast, accessible web application in **React 18, TypeScript, TailwindCSS, and Vite**. Integrates client-side reading progress, browser history popstate synchronization, and dynamic deep search.
